# Manual Run Review

Use after every manual run until the process is promoted.

- [ ] Did the bot do exactly one job?
- [ ] Did it read the required state file first?
- [ ] Did it use the correct source systems?
- [ ] Did it report zero-result or failed sources honestly?
- [ ] Did it stay inside its hard budget?
- [ ] Did it follow the output contract?
- [ ] Did it avoid unsupported facts or invented signals?
- [ ] Did it respect the approval boundary?
- [ ] Did it use the silence rule correctly?
- [ ] Would I use the output unedited?

## Correction log
If you correct the same behavior, add the rule to the bot spec or Skill. Do not leave the fix only in chat.
